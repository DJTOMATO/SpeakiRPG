# SpeakiMod+ Unofficial Client for Android

## for EN
A client for play SpeakiRPG with SpaekiMod+(developed by [Glas](https://github.com/DJTOMATO/SpeakiRPG))  
This project is simply an application that loads and launches SpeakiMod+. It does not include Glas's deliverables.  
If the mod is updated, they will be automatically activated.  
(Otherwise, this app will likely fail to launch.)  
To install this app, download the APK file from the [Releases](https://github.com/venoroa1358/SpeakiRPGClient/releases) section and follow the instructions.

### Requirements
- Android 8.0 or later
- The ability to install APK files from unknown sources

### TroubleShooting
- I launched the app, but the mod didn't start.
  - Please force quit the app and then restart it.
- The UI is hidden, so I can't use it.
  - Try rotating your smartphone. You may be able to access UI elements that were previously hidden.
  - Open the mod's options and set the UI Scale to the lowest value.

## for JP
[Glas](https://github.com/DJTOMATO/SpeakiRPG)さんが開発した、SpeakiMod+をロードしながらスピキ育成を遊ぶためのクライアントです。  
このプロジェクトは、単純にSpeakiMod+をロードするだけのアプリケーションです。Glasさんの成果物は含んでおりません。  
SpeakiMod+の更新は自動的に適用されます。  
(または、アプリが起動しなくなるでしょう。)  
インストールするには、[Releases](https://github.com/venoroa1358/SpeakiRPGClient/releases)からapkファイルを取得して指示に従ってください。

### 要件
- Android 8.0 以上
- 提供元不明のAPKファイルをインストールできること

### トラブルシューティング
- アプリを起動したのに、modが適用されていない。
  - タスクキルしてもう一度アプリを起動してください。
- UIが隠れて操作することができない。
  - スマートフォンの向きを変えてください。隠れていたUIが表示されるようになる場合があります。
  - modの設定から、「UIスケール」を最小にしてください。
